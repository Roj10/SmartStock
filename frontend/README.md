# SmartStock – Frontend

Interface web do SmartStock, feita com **React 19 + Vite**. Ela só funciona junto com o backend (API em
`http://localhost:8080`).

```bash
npm install     # instala as dependências (só na primeira vez)
npm run dev     # abre em http://localhost:5173
npm run build   # gera a versão de produção em dist/
npm run lint    # confere o código com o Oxlint
```

Requer Node.js 20.19+ ou 22.12+.

As instruções completas (instalação, backend, contas de demonstração, estrutura e problemas comuns) estão no
[README principal](../README.md).
